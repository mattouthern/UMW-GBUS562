# Week 02

Materials for week 2 of GBUS 562: AI Language Models.

## Contents

- [Prompt Lab](prompt-lab.html): a single-page web app for testing prompts against Claude (`claude-sonnet-5`), built with Claude Code. Download the file, open it in any web browser, and paste your Anthropic API key (it is never saved). Set an optional system prompt, chat with Claude, start a new conversation, or export the conversation as a Markdown file.
